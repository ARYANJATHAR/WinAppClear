## Description

WinAppClear is an open-source Windows uninstaller that helps you manage installed software and review what it leaves behind.

Find an app, run its own uninstaller, then inspect detected leftover files and registry entries. Confidence labels help you review potential matches before choosing what to remove. WinAppClear backs up supported selected cleanup items before removing them; a program's own uninstaller controls its separate changes.

Start Install Monitor before installing a program to compare before-and-after snapshots. Inspect recorded changes later, alongside your removal history and available cleanup backups.

Additional tools help you review supported Windows apps and browser extensions, check supported updates through Windows Package Manager, and manage stubborn or unwanted files. Android app management requires separately installed Android Platform Tools, USB debugging and authorization on the connected device.

WinAppClear requires Windows 10/11 x64 and administrator permission for its desktop tools. The installer includes the .NET runtime. Some features need separate tools or an internet connection. Installation logs may include unrelated activity during recording; leftover detection cannot guarantee a complete match. Review changes before proceeding.

Free and open source under the MIT license. Source code and support: https://github.com/ARYANJATHAR/WinAppClear.

## Feature bullets

- Search installed programs and use size, date and activity filters.
- Uninstall selected desktop apps and review detected leftovers.
- Inspect confidence labels and keep uncertain matches unchecked.
- Record installations manually and inspect saved changes.
- Review removal history and restore available backed-up cleanup items.
- Review supported Windows apps and browser extensions.
- Check supported updates through Windows Package Manager.
